# content/

Working media + queue. Most of this is gitignored (see `.gitignore`).

```
content/
├── briefs/      # your brief JSONs (Step 1 output)
├── clips/<id>/  # Higgsfield clips per draft
├── renders/     # stitched + finalized mp4s
├── queue/<id>.json   # review-queue items (draft/approved/published)
├── music/       # LICENSED audio only
├── captions/    # .srt files
└── sample/      # example brief (checked in)
```
